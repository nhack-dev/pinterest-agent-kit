# Pinterest エージェントキット

あなたの AI エージェント（Claude Code など）がこのフォルダを読むと、Pinterest の**ピンづくりと数字のふり返り**を続けられるようになるキットです。

**費用は、Pinterest API は無料。** このキットはほかのサーバーに何も送りません。

---

## 最初の10分

1. このフォルダを自分のパソコンに置く（受け取ったリポジトリを clone する）
2. `python3 --version` で 3.11 以上か確かめる
3. `cp .env.example .env` → 下の「キーの取り方」でキーを入れる
4. コマンドは既定で「送る予定を表示するだけ」（dry-run）。**`--go` を付けたときだけ本当に動きます**
5. まず見るだけ（何も送られない）：
   ```
   python3 scripts/pin_boards.py
   python3 scripts/pin_create.py --file templates/pin.md
   ```
6. `--go` を付けると本当に動く（`python3 scripts/pin_boards.py --go` でボードIDが出る）
7. AI エージェントに「AGENT.md を読んで、今日の分をやって」

---

## キーの取り方

1. Pinterest を **ビジネスアカウント** にする
2. https://developers.pinterest.com/ でアプリを作る → 最初は「試用アクセス（Trial）」
3. アプリの画面でアクセストークンを作り（権限 boards:read pins:read pins:write）、`.env` の `PIN_ACCESS_TOKEN` へ
4. 試用のあいだは `PIN_SANDBOX=1`（作ったピンは**自分にだけ見える**練習用）。公開したくなったら、アプリの画面の「Upgrade」から標準アクセスを申請（審査あり・アプリを使っている様子の動画を求められることがある・時間がかかることがある）→ 通ったら `PIN_SANDBOX=0`

## できること・できないこと（公式ドキュメントで確かめた範囲）

| やりたいこと | できるか | 道具 |
|---|---|---|
| 自分のボードの一覧 | できる | `pin_boards.py` |
| ピンを作る（画像URLから） | できる（試用アクセスのあいだは自分にだけ見える） | `pin_create.py` |
| ピンの数字（表示・保存・クリック） | できる（90日まで） | `pin_analytics.py` |
| 他人の画像を載せる | やらない（公式の決まりで、自分で作った新しいコンテンツ用の機能） | ― |

- タイトル100字・説明800字・代替テキスト500字まで
- 画像は公開URLに置く（縦長 2:3 がおすすめ）

## 道具

| 道具 | すること |
|---|---|
| `pin_boards.py` | ボードIDを調べる |
| `pin_create.py` | ピンを作る（`templates/pin.md` の形の md から） |
| `pin_analytics.py` | 作ったピンの数字 → `data/pin-<日付>.csv` |

## 毎日の動かし方（cron の例）

```
0 7 * * 1 cd /path/to/pinterest-agent-kit && python3 scripts/pin_analytics.py --go >> data/cron.log 2>&1
```
`/path/to/` は自分の置き場所に替えてください。


## 困ったとき

| 出たもの | 意味 | やること |
|---|---|---|
| HTTP 401 / 403 | トークン・権限・アクセスの段階 | 権限と `PIN_SANDBOX` を確かめる |
| ピンが人に見えない | 試用アクセス（サンドボックス）のまま | 標準アクセスを申請する |
| HTTP 429 | 呼びすぎ | 時間をあける |

## このキットは N-Hack のAIエージェント専用です

このキットは N-Hack の受講生さん専用のプレゼントです。**N-Hack のAIエージェント
（N-Hack のプラグインを入れた Claude Code など）が、このパソコンで動いていること**を
前提にしています。

- どのスクリプトも、最初に `scripts/nhack_gate.py`（門）を通ります。門は、このパソコンに
  N-Hack のAIエージェントの「印」があるかを**読むだけ**で確かめます（ネットにつなぎません・
  何も書き換えません・プラグインには一切触れません）。
- 印が足りない環境では、スクリプトは動かずに止まります（終了コード 2）。この環境でだけ
  動くのが正しい姿です。
- いま N-Hack 環境かどうかは、次のコマンドで確かめられます。

```bash
python3 scripts/nhack_gate.py
```

N-Hack 以外のパソコンにコピーしても動きません。受講生ページ・コンサルチャンネルの案内に
沿ってご利用ください。
