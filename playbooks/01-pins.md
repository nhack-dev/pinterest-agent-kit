# 03 Pinterest

## 先に知っておくこと
- 試用アクセスのあいだは、作ったピンは **自分にだけ見える**（サンドボックス）。ここで型を練習する
- 公開するには標準アクセスの申請が要る（アプリの画面の Upgrade。審査あり・使っている様子の動画が求められることがある）
- 公式の決まり：**自分で作った新しいコンテンツ** を載せるための機能。他人の画像を載せない

## ピンの型
| 欄 | 決まり |
|---|---|
| 画像 | 縦長（2:3 がおすすめ）・公開URLに置く・文字は大きく1〜2行 |
| タイトル | 100字まで。検索される言葉を前に |
| 説明 | 800字まで。何が分かるか・誰向けか・次に何をすればいいか |
| 代替テキスト | 500字まで。画像に何が写っているか |
| リンク | 自分のブログ・note・動画など（任意） |

## 流れ
1. `python3 scripts/pin_boards.py --go` でボードIDを調べ、`templates/pin.md` に書く
2. `drafts/pin-YYYY-MM-DD.md` → `python3 scripts/pin_create.py --file ...`（dry-run）→ OK → `--go`
3. 週1回 `pin_analytics.py --go`（保存 SAVE と外部クリック OUTBOUND_CLICK を見る）
